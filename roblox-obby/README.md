# Roblox Obby Kit — установка за 2 минуты

Готовая полоса препятствий: 11 стейджей + золотой финиш. Прыжки по платформам, лава,
узкие балки, движущиеся платформы, вращающаяся штанга, исчезающие плитки, подъём,
конвейер, мост, лифты и лестница. Чекпоинты, жёлтые кнопки SKIP, таймер забега,
leaderstats (Stage / Wins), сейв лучшего стейджа и времени через DataStore.
Та же трасса, что в веб-версии `obby.html`.

Файлы:
- `RobloxObby.rbxlx` — **готовый place-файл**: двойной клик → откроется в Roblox Studio → Play.
- `ObbyServer.luau` — серверный скрипт (трасса, чекпоинты, лава, движущиеся части, сейвы).
- `ObbyHud.luau` — клиентский HUD (стейдж, таймер, рекорд, баннеры, кнопки сброса).
- `build.ps1` — пересобирает `RobloxObby.rbxlx` из двух `.luau`.

## 1. Открыть готовый файл (вариант А)
1. Двойной клик по **`RobloxObby.rbxlx`** (или Studio → File → Open from File).
2. Нажми **Play** — трасса соберётся сама.
3. Хочешь сейвы в Studio: Home → Game Settings → Security → **Enable Studio Access to API Services: ON**.

## 2. Установка вручную (вариант Б)
1. Studio → New → **Baseplate**.
2. Explorer: **ServerScriptService** → `+` → **Script** → вставь целиком `ObbyServer.luau`.
3. Explorer: **StarterPlayer → StarterPlayerScripts** → `+` → **LocalScript** → вставь `ObbyHud.luau`.
4. Play. (Baseplate и дефолтный спавн скрипт сам удалит.)

## 3. Как играть
- WASD — бег, Пробел — прыжок. Цель — добежать от старта до золотого финиша, не упав в лаву.
- Зелёные **чекпоинты** — при касании сохраняют прогресс; после смерти респавн на последнем.
- Жёлтые **SKIP** рядом с чекпоинтом — пропустить стейдж (перезарядка 3 сек).
- Красные **лава и штанга** убивают. Упал в пустоту — тоже смерть.
- **Таймер** стартует с первого чекпоинта и останавливается на финише; лучший результат — в рекорде.
- Зашёл второй раз — прогресс подгрузится, можно продолжить с сохранённого стейджа.
- Кнопки в HUD: **⟲ Сброс** (к текущему чекпоинту) и **⏮ С начала** (новый забег).

## 4. Настройки
В начале `ObbyServer.luau` — таблица `CONFIG`:
```lua
WalkSpeed = 20        -- скорость бега
JumpPower = 52        -- сила прыжка
SkipEnabled = true    -- жёлтые кнопки SKIP
SkipCooldown = 3      -- перезарядка скипа, сек
MoverSpeed = 1.7      -- скорость катающихся платформ
ElevatorSpeed = 1.1   -- скорость лифтов
SpinnerSpeed = 1.15   -- скорость вращающейся штанги
BlinkOn / BlinkOff    -- исчезающие плитки: сколько стоят/исчезают
ConveyorSpeed = 12    -- сила конвейера
SaveData = true       -- DataStore-сейвы (лучший стейдж и время)
```
После правок: `powershell -ExecutionPolicy Bypass -File build.ps1`, чтобы обновить `.rbxlx`.
Хочешь новую трассу — добавь свою функцию в таблицу `STAGES`: верни `Vector3` (смещение
следующего чекпоинта), и стейдж появится сам, со своими номером и чекпоинтом. `StageCount`
в CONFIG должен совпадать с числом стейджей (для HUD).

## 5. Публикация → ссылка
1. File → **Publish to Roblox** → New Experience → название (например «Super Obby») → Create.
2. Ещё раз **Publish**. Игра появится в твоём аккаунте: **roblox.com/games/<ID>** — это ссылка.
3. Чтобы играли другие: Studio → Game Settings → Permissions → Public.

## Частые ошибки
- `Script` должен лежать именно в **ServerScriptService**, а HUD — в StarterPlayerScripts.
- Нет leaderstats/чекпоинтов — скрипт не в ServerScriptService или вставлен не целиком.
- `DataStore can't be accessed` в Studio — включи API Services (п.1.3), в опубликованной игре работает само.
- Игрок возрождается не там — чекпоинт привязывается при касании; сбрасывайся кнопкой в HUD.
- Слишком сложно/легко: крути `WalkSpeed`, `JumpPower` и скорости движущихся частей в CONFIG.

Веб-версия той же трассы: `obby.html` в корне проекта.
